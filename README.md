# Практическая работа №1: Резервное копирование и восстановление

* **ФИО:** Нурманбетов Мансур Шарафатдинулы
* **Вариант:** Строительная компания (400 ГБ, 150 МБ/с, раз в сутки, RPO 8 ч, RTO 4 ч)

## Назначение скриптов
* `make_test_data.py` — генерирует тестовую структуру директорий и файлы для проверки.
* `backup.py` — основной скрипт, выполняющий создание бэкапов с ротацией, проверку целостности (SHA-256), детальный отчёт об ошибках и аварийное восстановление с замером времени.

## Команды запуск
1. Сгенерировать тестовые данные:
   ```bash
   python make_test_data.py
